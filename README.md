# 🧠 AI Generator for HTML/CSS/JS Editing via LLM

Этот проект представляет собой систему, которая по текстовой команде редактирует HTML/CSS/JS код с помощью LLM. Генерация осуществляется через API доступа к модели `llama-3-70b` от Groq.

---

## 🚀 Быстрый старт

### 📦 Сборка контейнеров

Перед запуском убедитесь, что у вас установлен Docker и Docker Compose и ВЫ НАХОДИТЕСЬ В НУЖНОЙ ВЕТКЕ:

```bash
docker-compose build --no-cache
```

> Используется `--no-cache`, чтобы гарантировать полную пересборку с актуальными зависимостями.

Затем вводим команду

```bash
docker-compose up
```

Далее переходим по url адресу

```bash
http://localhost:3000
```

---

### 🌐 VPN обязателен

Перед запуском контейнеров **обязательно активируйте VPN**.  
Проект обращается к **Groq API**, который может быть недоступен из некоторых регионов без VPN.

---

### 🧠 Используемая модель

Проект использует модель:

```text
llama-3-70b-8192 (версия: versatile) — от Groq
```

Это мощная и быстрая модель, отлично подходящая для генерации HTML/CSS/JS правок.  
Если у вас есть ресурсы, вы можете запустить аналогичную **open-source версию** локально:

- `Meta Llama 3 70B`
- Запуск возможен через Ollama, vLLM, LM Studio, TGI и другие фреймворки

Однако в текущей реализации используется **удалённый API** по причине ограничений на локальный запуск.

## 🔧 Переменные окружения (.env)

В контейнере уже используются встроенные ключи Groq API **для удобства локального тестирования**.  
Но при развёртывании рекомендуется создать свой `.env` файл со следующими переменными:

```env
GROQ_API_KEY=your_groq_api_key_here
```

Затем указать путь к `.env` при запуске или пробросить через Docker Compose.
